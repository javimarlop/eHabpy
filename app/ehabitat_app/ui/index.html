Input variables

The study area and the variables (GeoTIFFs) at two scales: the plot scale (the study area, with the fine pixel size at which the HFTs are mapped) and the ecoregion scale (a coarser pixel size, for the similarity of the HFTs in their ecoregion). They can also be downloaded from the catalog of MonitorEO.

Study areas

a vector file: each ID is a study area where the HFTs are mapped
an integer column; "cat" = one ID per polygon
optional: the names shown with the IDs

Map

study area and preview of the chosen variable

Set of variables

A set is a subfolder of inVars: its GeoTIFFs are the variables of the study area and those of its subfolder ecoregion, the variables of the ecoregion. The order of the files is the order of the variables (the first one defines the pixels analysed). Unticked variables go to _excluded, which is not used.
